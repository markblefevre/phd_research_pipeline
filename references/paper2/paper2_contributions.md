# Paper 2 — Three Main Contributions

## 1. Conditional value of contextual NLP

The paper moves beyond an unconditional comparison of lexical, transformer-based, and generative sentiment measures by asking whether their relative economic informativeness depends on **disclosure innovation**.

Disclosure innovation can encompass both:

- **Textual novelty** — how much the language changes relative to the prior filing.
- **Sentiment innovation** — how much the sentiment signal itself changes relative to the prior filing.

The central question is whether contextual and generative models add more value when the disclosure contains more genuinely new information.

## 2. Common economic validation of independently constructed sentiment measures

The study compares a domain-specific lexical measure, a contextual transformer, and a generative LLM on the same disclosure sample and against the same market outcome.

The sentiment measures are constructed independently of realized returns and then evaluated using abnormal returns. This separates **sentiment measurement** from **return prediction** and makes the comparison across technologies cleaner.

## 3. Extension of Japanese disclosure research from model comparison to information-conditioned model performance

Using Japanese annual securities reports, the paper extends prior work by examining whether the relative usefulness of alternative sentiment technologies varies with the degree and type of disclosure innovation, rather than asking only which model performs best on average.

This combines model comparison, disclosure change, and short-window market validation in a single setting.

---

### Contribution hierarchy

- **Primary contribution:** Conditional value of contextual NLP.
- **Methodological contribution:** Common economic validation of independently constructed sentiment measures.
- **Empirical / institutional contribution:** Extension of Japanese disclosure research to information-conditioned model performance.
